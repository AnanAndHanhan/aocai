# 澳彩项目

更新时间：2026-10-31

本项目是维护生肖卡资料、开奖记录、图片解释、交叉分析与历史复盘的 Markdown 知识库。“澳门路子”为资料分析专题。资料用于文本研究、归档和娱乐性统计，不应视为可靠的随机开奖预测。

## 文件入口

| 文件 | 用途 |
| --- | --- |
| PROJECT_HANDOFF_FINAL.md | 完整交接与日常流程 |
| PROJECT_HANDOFF.md | 快速交接 |
| 基础资料.md | 2026年号码、生肖分类、外号和历史复盘 |
| 决策记录.md | 有来源和日期的纠偏规则 |
| 开奖记录.md | 历史开奖记录，首号和特码分开 |
| 项目记忆.md、对话摘要.md | 背景与恢复记忆 |
| RESTORE.md | 仓库恢复与同步 |
| CHANGELOG.md | 文档维护记录 |

接手前依次阅读本文件、最终交接、基础资料、决策记录、开奖记录。历史记录目前截至2026年第190期（7月9日），不能当作最新开奖。

```bash
git status --short --branch

```

维护后更新 CHANGELOG.md，检查差异，只暂存本次相关文件，然后提交推送；不可覆盖无关改动。

## 当前执行规则（2026-10-31）

来源：用户恢复版总指令、日常维护流程及第304期后的明确纠偏。适用于后续资料分析；与历史条目冲突时，本节及用户更新指令优先。

- 优先级：用户最新指令及当期标注、最新纠偏、决策记录、基础资料、交接和历史摘要。
- 每期独立分析；先核对有效区域，逐句原义、逐字线索，再多资料交叉，禁止仅凭部首猜生肖。
- 暗码、解九肖完全忽略；被排除区域及指定不参考的右下角生肖不参与分析。
- 大字笔画仅限跑马、跑狗指定位置，只取总笔画，不拆左右；同一固定提示每期只计一次。
- 西天取经肖：虎、龙、马、猴、猪。“远”补查边远肖鼠、猪。
- 万贯家财、万贯身家补查多钱肖、多金肖：猴、鸡、狗、猪、龙、马、羊；同源分类不重复计权。“金钱肖”未另有确认名单时，核对已有表，不自行造表。
- 上期首号生肖最高降权，末尾特码单独记录；当期对冲依据跑狗底部提示，两个生肖都降权。
- 挂号对应生肖最高降权；爆肖仅对点名生肖次级降权。每项注明来源，降权不绝对排除。
- 仅在用户要求时查询开奖，限定 macaujc.com 的“新澳门六合彩”“开奖历史”“走势图”。近30/50期热门统计仅看特码。
- 完整输出：当期资料与有效区域、每图逐句逐字释义、生肖对应证据、集中交叉、所有降权及原因、排序主六肖与防三肖、不确定及矛盾线索。
- 复盘区分原分析与真实开奖，新增规则注明来源、日期、适用范围，禁止事后附会。
