更新时间：2026-10-31

## 非标准谜面处理

资料中的词语、短句、四字提示不必是标准成语，也不必完全通顺；它们是生肖谜面。保留可见原字，先尝试说明整体字面或可成立的意境，再逐字逐词查基础资料与决策记录中的生肖分类、外号、主格、VIP对应及允许的数字线。不能仅因不合常用语而停止分析或把可辨文字当无效，也不能擅改成标准成语后推断。文字识读不清与文字已清楚但语义不顺须分开标注；候选对应说明表格来源、强弱和交叉，不据此无限联想、仅凭部首猜肖或突破笔画限制。

复盘入口：[复盘索引](复盘索引.md)、[每期复盘模板](复盘模板.md)。每期开奖结果后无论预测对错均复盘，并区分原有线索和事后观察。
